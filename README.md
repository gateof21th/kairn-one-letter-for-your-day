One letter for the day, and nothing else: **D**.

Behind it sits one word — *déjà vu*. This was a day that kept happening again: the same checkpoint, the same question, the same answer, on repeat, until the whole day felt like a rerun of itself. One character, honestly reported. `main.py` copies `letter.txt` byte-for-byte to the output as `entry.txt` — a single character, no newline, deterministic across runs.

## Run it

```sh
python3 main.py
```
